초급 통과 기준: 걸림 3회 이하
속도
느리게 보려면 영상 안의 설정(⚙)에서 재생 속도를 0.5배·0.75배로 바꾸세요. 전체 화면도 영상 안에서 켤 수 있어요.
    1. 순서 익히기

    영상을 보며 동작 5개의 순서를 외워요. 동작마다 32박자씩, 다 합쳐 160박자예요.

    2. 천천히 따라 하기

    속도를 0.5배·0.75배로 낮춰 음악에 맞춰 따라 해요. 걸려도 끝까지 이어서 해 보세요.

    3. 끝까지 한 번에

    1배속으로 처음부터 끝까지 걸리지 않고 해요. 마지막은 'V'자 앞멈춤으로 마무리!

    4. 심사 받기

    자신 있으면 체육 시간에 선생님께 심사를 받아요. 통과하면 다음 급수로 올라가요.

    공인급수표 9급 ~ 1급

    동작마다 32박자씩 음악에 맞춰 이어서 하고, 마지막은 'V'자 앞멈춤으로 끝내요. 통과 기준(걸림 허용 횟수)은 교사 설정을 따라요.

    교사 화면

    심사·현황판·인증서·명단은 선생님만 써요. 비밀번호 네 자리를 넣어 주세요.

    처음 비밀번호는 1234예요. 교사 화면의 명단·설정에서 바꿀 수 있어요.

    학생 고르기

    왼쪽에서 학생을 고르세요명단이 비어 있으면 명단·설정에서 학생을 먼저 넣어 주세요.

    기록이 바뀔 때마다 선생님 구글 드라이브의 '줄넘기 공인급수' 폴더에 저장돼요. 처음 한 번만 연결하면 돼요.

    2. 배포 → 새 배포 → 유형 '웹 앱' → 실행 사용자 '나', 액세스 '모든 사용자' → 배포 → 권한 허용 → 웹 앱 URL 복사

    아직 연결하지 않았어요.
